01

Classroom scope

All 90 tools are real local read-only handlers. No Slack, Jira, GitHub or production database integration is implied. Search, model calls and context measurements use the actual Agent SDK.

02

Measure honestly

getContextUsage detail full counts context categories. Compare categories by kind and id, not English names alone. Deferred schemas are out of window. JSON catalog bytes are not tokens. Post-result totals include different generated messages and discovery calls.

03

Auto thresholds

The requested value auto:5 does not guarantee a search call. Below its context-percentage threshold, upfront loading is expected. Counts, schemas, model context, deployment support and organizational settings affect behavior.

04

Discovery experiment

Only the course-notes tool name, description and searchHint improve. The returned record remains the same. One successful query is illustrative; it cannot establish a statistically significant accuracy gain.

05

Version-aware support

The supplied slides describe older gateway defaults and 4.5-generation support. Current official docs say gateways default on with newer Claude Code versions and document a broader supported-model set. Installed package behavior and actual events take precedence. Microsoft Foundry deployments and policy restrictions may still force fallback.

06

Documented limits

Official docs describe up to 10,000 tools and up to five matches per search by default. This application registers 90 tools and records returned references; it does not benchmark the limit or claim every search returns exactly five.

07

Always-loaded critical tool

Only catalog_status is marked alwaysLoad true. It stays eligible for immediate use. Other tools remain deferred when search is active; authorization still applies.

08

Cost and privacy

Live model queries and full context counts may incur API usage. Each experiment has an SDK budget threshold of $0.65, which is not a prepaid cap. Only the configured model credential is needed; secrets and all teaching media remain excluded from Git.
