Configure and run the app.

Install the SDK, configure your key and run the classroom comparisons.

Application labWhat you will learnHow to runArchitecture & workflowCode walkthrough
01

Prerequisites

Install Node.js 24 or later, use TypeScript for this application and ensure model access plus API credit. On Windows install Git for Windows if the SDK requests Git Bash. Python is only needed to regenerate teaching HTML.

node --version
npm --version
02

Install and create your .env file

From presentations, enter this application. Preserve an existing .env. Enter your own Anthropic key privately; no GitHub token or Managed Agents IDs are required.

cd .\agent-sdk\lesson26-tool-search
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start the web application

Keep the terminal open. Use the exact URL printed by startup. The server loads .env through the Node startup option.

npm start
# http://127.0.0.1:3126
04

Compare search on and off

Run Search on and Search off. Inspect actual native search results, completed handlers and full context measurements. The browser comparison keeps one row per run. CLI prints the same event protocol.

npm run sample:env -- search-on
npm run sample:env -- search-off
05

Explore default and automatic thresholds

Unset uses the installed runtime default; auto uses 10% and auto:5 uses 5%. Search may remain off below the threshold. Do not infer activation only from the requested setting.

npm run sample:env -- default
npm run sample:env -- auto
npm run sample:env -- auto-five
06

Improve discovery and pin one critical tool

Run Discovery, then Critical tool. Compare metadata and actual execution. Pinning status should not force every other catalog schema upfront.

npm run sample:env -- discovery
npm run sample:env -- always-load
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3126
# Windows if needed: CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Only your model key is required. Keep it local and restart after edits. Existing shell variables take precedence.

Troubleshooting

Use Node 24+, API credit and a supported model. Configure Git Bash on Windows if requested. If the port is occupied, use the printed existing-app URL or change PORT. A missing ToolSearch call in auto mode can be expected below the threshold. Review actual context categories. Measurement failure remains visible instead of being replaced with an estimate.
